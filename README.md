# CountriesGuessor

Статическая игра: весь код в одном `index.html`.

## Запуск (GitHub -> Vercel)
1. Загрузите содержимое папки в репозиторий GitHub (index.html должен лежать в корне).
2. Vercel -> Add New -> Project -> выберите репозиторий -> Framework Preset: Other -> Deploy.

## Онлайн и режим «Столицы» (Supabase)
Project URL и publishable-ключ уже вшиты в index.html.
Supabase -> SQL Editor -> New query -> вставьте весь текст из supabase/capitals_setup.sql -> Run.
Внизу везде должно быть OK. Скрипт можно запускать повторно.
**Запустите его заново после этого обновления**: он добавляет уровни сложности стран в «Столицах».

## Что нового в v5
- Главный экран сразу открывается в новом дизайне (раньше он появлялся только после перехода между экранами).
- Над ником: Premium и выбранный титул. Под ником: ранг.
- Ранги за выигранные матчи (с ботом, слова, «Столицы»): 1 Новичок, 5 Путешественник, 10 Следопыт, 20 Исследователь, 50 Навигатор, 100 Картограф, 250 Эксперт, 500 Мастер, 750 Чемпион, 1000 Легенда. Пороги задаются массивом `RANKS` в `index.html`.
- Анимация «Новый ранг!» после матча, на котором достигнут порог.
- Титулы: вкладка «Титулы» (применить / снять, предпросмотр ника) и вкладка «Ранги» (лестница и прогресс).
- Победы и поражения в «Столицах» теперь учитываются в статистике.
- Новых SQL-миграций в этой версии нет.

## Что в версии v4
- Единый стиль всех экранов (магазин, титулы, статистика, настройки, персонаж, лобби, выбор режима) как у главного меню.
- Магазин: боксы-квадраты, «Бокс стикеров» с анимацией открытия и прокручиваемой коллекцией, Premium $67 с превью ника.
- Цены (константы BOXP, STKP, GOLDP в index.html): бокс титулов 100, бокс стикеров 85, золотой бокс 250.
- Награда за победу онлайн (слова и «Столицы»): 20–25 монет; матч с ботом: 10.
- Лобби: вкладки Countries / Cities / Mixed / Столицы; «Столицы» — 3 сложности (10/5/3 ❤️ и свой набор стран).
- Профиль (look, титул, Premium) отправляется в базу после любого изменения прогресса.
